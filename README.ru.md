![ManipStudio: симуляция робота, программа движений и графики моментов](docs/images/manipstudio.png)

Проект на C++ для расчёта кинематики, планирования движений и оценки нагрузок
в суставах шестикоординатных манипуляторов. Приложение ManipStudio позволяет
настроить модель и исследовать результаты через графический интерфейс.

Задав геометрию робота, массы и инерции звеньев, а также полезную нагрузку,
можно рассчитать положение инструмента по углам суставов, подобрать углы для
заданной позы и построить движение в пространстве суставов, по прямой или дуге.
Затем — проверить траекторию на столкновения, выход за пределы суставов
и требуемые моменты двигателей.

Код пригодится для экспериментов с конструкцией робота, сравнения нагрузок
и режимов движения, изучения алгоритмов робототехники до испытаний на оборудовании.
Расчётное ядро можно использовать из C++ отдельно от графического интерфейса.
Точность результатов зависит от параметров заданной модели.

## Возможности

- Интерактивная 3D-модель, путь TCP и воспроизведение по шкале времени.
- MoveJ, MoveL, MoveC, перемещение TCP и программы движений в JSON.
- Настройка DH-геометрии, пределов суставов, динамики звеньев и груза.
- Проверка столкновений, ограничений скоростей, ускорений и моментов.
- Графики движения и моментов с экспортом в CSV.
- Русский и английский интерфейс.

## Сборка и запуск

Нужны компилятор C++17, CMake, Ninja, Git и Qt 6.4+ с модулями Quick, Quick Controls, Quick3D, Charts и Test.
Для Windows используйте окружение MSYS2 UCRT64.

```bash
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Debug
cmake --build build --parallel 8
./build/Studio/ManipStudio
```

В Windows запускайте `./build/Studio/ManipStudio.exe`.
Настройки доступны в приложении и сохраняются в `ManipulatorSettigns.ini`.
Пример программы движений: [Studio/examples/demo_program.json](Studio/examples/demo_program.json).
